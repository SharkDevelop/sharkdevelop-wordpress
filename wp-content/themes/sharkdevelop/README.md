# Shark Develop Theme

Custom theme for the new Shark Develop frontend.

## Boundaries

- This theme owns frontend templates, layout, styles, and small frontend scripts.
- Project data belongs to the `Shark Develop Core` mu-plugin.
- Elementor is not a dependency for this theme.
- WordPress remains the CMS for pages, projects, blog posts, media, translations, and SEO.

## Current Structure

- `inc/` - theme setup, assets, helper functions.
- `template-parts/` - reusable PHP partials.
- `assets/css/` - frontend and editor styles.
- `assets/js/` - small frontend scripts.
- `archive-sd_project.php` - project archive.
- `single-sd_project.php` - project detail template.
