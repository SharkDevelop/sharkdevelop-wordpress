# Codex Workflow Prompts

## Analyze

```text
Проанализируй текущую задачу в этом WordPress-проекте. Сначала прочитай AGENTS.md и релевантные docs/. Не меняй файлы, пока не опишешь кратко, что нашел и какой план действий.
```

## Implement

```text
Сделай задачу в ветке dev. Сначала проверь Git status и структуру проекта. Вноси только необходимые изменения, не трогай production, uploads, wp-config.php, дампы базы и сгенерированные CSS Elementor.
```

## Verify

```text
Проверь внесенные изменения локально. Если нужны команды проверки, выполни их и кратко опиши результат. Отдельно укажи, если что-то проверить не удалось.
```

## Prepare Deploy

```text
Подготовь изменения к dev-деплою. Проверь, что Git чистый или перечисли, что нужно закоммитить. Не запускай production-деплой. Dev-деплой выполняется командой ./scripts/deploy-dev.sh.
```

## Debug Deploy

```text
Разбери ошибку dev-деплоя. Не меняй production. Проверь scripts/deploy-dev.sh, Local окружение, SSH-доступ, экспорт БД, rsync uploads и WP-CLI на dev.
```
